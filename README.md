## 📖 Overview

**⚡𝗛𝗘𝗠𝗔𝗡𝗧𝗛⚡** is a fully modified, high-performance fork of the powerful Wanda Zebra project. It is meticulously designed to be a one-stop solution for Telegram power users who need to mirror content to the cloud, leech files directly to Telegram, and perform advanced video processing on the fly.

---

## ✨ Key Features

### 📥 1. High-Speed Downloads
- **Multi-Source Support**: Direct Links, Torrents (Magnet/File), Mega.nz, and 1000+ sites via `yt-dlp`.
- **Mirroring**: Upload files directly to **Google Drive** (including Team Drives) or any cloud supported by **RClone** (OneDrive, Terabox, Mega, Dropbox).

### 🎬 2. Advanced Video Tools (`-vt`)
Process your videos directly within the bot using the powerful FFMPEG integration:
- **Compression**: Smart compression to save data without losing quality.
- **Trimming**: Exact trimming by timestamp.
- **Merging**: Combine Video, Audio, and Subtitles effortlessly.
- **Watermarking**: Branding your content automatically.

### ⚙️ 3. Personalized Settings
- **`/usetting`**: A robust menu for users to customize their experience.
- **Custom Thumbnails**: Set per-user or global thumbnails for leeched files.
- **Flexible Captions**: Dynamic placeholders for file metadata in captions.
