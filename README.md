# 🤖 DC BoTs - Advanced Telegram Mirror Leech Bot

Welcome to the **DC BoTs** configuration and deployment repository. This repository contains the templates and guides required to deploy a high-performance Telegram Mirror-Leech Bot based on the **WZML-X** (Wanda Zebra) project.

## 🌟 Key Features

- **Mirror & Leech**: High-speed downloads from Direct Links, Torrents, Mega, and 1000+ sites (via yt-dlp).
- **Advanced Video Tools (-vt)**: FFMPEG-powered tools for:
  - Video Compression
  - Trimming & Cropping
  - Merging (Video, Audio, Subtitles)
  - Custom Watermarking
  - Metadata Editing (Title, Encoded By)
- **Cloud Integration**: Support for Google Drive (with Index Link) and RClone (OneDrive, Terabox, etc.).
- **User Customization**: Persistent user settings for thumbnails, captions, and more via `/usetting`.
- **Automation**: Auto-Merge mode and automated screenshot generation.

## 🚀 Getting Started

1. **Setup Config**: Copy `config.env.sample` to `config.env` and fill in your credentials.
2. **Deploy**: Follow the instructions in [deployment_guide.md](deployment_guide.md).
3. **Usage**: Refer to [Video_Tools_Manual.md](Video_Tools_Manual.md) for processing videos.
